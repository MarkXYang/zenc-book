# Getting Started

Let's start your Zen C journey!

There's a lot to learn in Zen C, but every journey starts somewhere. In this chapter, we'll discuss:

- **Installation**: Installing the `zc` compiler on Linux, macOS, or Windows/WSL, along with backend dependencies (GCC, Clang, or TCC).
- **Writing a "Hello, World!" Program**: Creating your first project directory, writing `.zc` source code, understanding Zen C's syntax, and compiling/running your binary.
- **Mastering `zc`**: Understanding how the `zc` command-line toolchain operates (`build`, `run`, `check`, `transpile`), configuring compiler options, and inspecting generated standard C11 code.

Let's begin by getting the Zen C toolchain set up on your machine!
