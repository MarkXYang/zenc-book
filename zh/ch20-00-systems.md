# 第 20 章 系统与安全关键编程

Zen C 从设计之初就专为系统级开发而打造：操作系统内核、裸机引导加载程序、嵌入式微控制器、高吞吐量金融交易引擎、图形管线，以及安全关键的航空航天电子设备或汽车控制单元。

在高级托管语言中，对底层硬件的访问要么被严格禁止，要么被包裹在运行缓慢且不透明的外部函数接口中。而在传统 C 语言中，编写底层代码往往需要牺牲类型安全、工效学体验以及现代语言工具支持。Zen C 通过为裸机系统与安全关键工程提供一等公民的原语，弥合了这一鸿沟：

1. **内联汇编（`asm { ... }` / `asm volatile { ... }`）**：直接访问特定 CPU 指令、周期计数器（`rdtsc`）、内存屏障（`mfence`）以及原子操作，并通过 `{var}` 实现无缝的变量绑定。
2. **原生 SIMD 向量化（`std/simd.zc`）**：提供 128 位（SSE/NEON）与 256 位（AVX/AVX2）向量类型（`f32x4`、`i32x4`、`f32x8` 等），支持编译器加速的逐分量算术与位运算。
3. **MISRA C:2012 合规模式（`--misra`）**：编译器自动验证并生成符合 MISRA C:2012 规则的车规级、安全关键代码（强制执行严格的布尔条件、穷尽分支和单出口返回）。
4. **多语言互操作（`--cpp`、`--objc`、`--cuda`）**：无需重写逻辑，即可将 Zen C 程序编译为以 C++17 运行时、Apple Objective-C 框架或 NVIDIA CUDA 设备核函数（`@global`）为目标的输出。
5. **在现有 C 代码库中嵌入 Zen C（`@export`、`@link_name`）**：将 Zen C 模块编译为静态库（`.o`、`.a`）或动态共享库（`.so`、`.dylib`、`.dll`），供任何标准 C 宿主应用程序调用。

## 安全关键的光谱

不同的系统领域对安全性和性能有着不同的诉求：

| 领域 | 核心诉求 | Zen C 解决方案 |
| :--- | :--- | :--- |
| **裸机与操作系统内核** | 硬件寄存器访问、内存屏障、精确的 CPU 指令 | `asm volatile { ... }`、裸指针（`*T`）、`@packed`、`@align` |
| **游戏引擎与数字信号处理 (DSP)** | 高吞吐量并行算术计算、每帧零分配 | `std/simd.zc`（`f32x4`、`f32x8`）、值类型、Arena 内存池 |
| **汽车与航空航天** | 确定性的控制流、零未定义行为、审计合规 | `zc --misra`、MISRA C:2012 检查器、静态边界检查 |
| **异构加速** | GPU 并行卸载、与现有 C++ 引擎互操作 | `zc --cuda`、`zc --cpp`、`zc --objc` |
| **旧有代码库现代化** | 逐步平滑迁移而无需推倒重写 | `@export`、`@link_name`、无缝的 C 头文件导入 |

## 本章你将学到什么

1. **[20.1 内联汇编与 Volatile](ch20-01-inline-assembly.md)**：编写 `asm` 与 `asm volatile` 代码块、使用 `{var}` 绑定输入/输出寄存器、处理条件代码破坏列表（clobbers）以及控制编译器优化屏障。
2. **[20.2 原生 SIMD 向量化](ch20-02-simd.md)**：使用来自 `std/simd.zc` 的 128 位和 256 位向量类型、执行逐分量算术（`+`、`-`、`*`）与位运算，并理解硬件向量降级机制。
3. **[20.3 MISRA C:2012 合规模式](ch20-03-misra-mode.md)**：启用 `--misra` 模式、理解 `zc` 强制执行的核心 MISRA 规则、审查防御性 C 输出，并编写可验证的安全关键软件。
4. **[20.4 多语言互操作：C++、Objective-C 与 CUDA](ch20-04-cpp-objc-cuda.md)**：生成 C++（`--cpp`）、Objective-C（`--objc`）和 NVIDIA CUDA（`--cuda`）源代码、将指针映射为 `nullptr`，并构建多语言应用程序。
5. **[20.5 在 C 程序中嵌入 Zen C](ch20-05-embedding-zc.md)**：使用 `@export` 和 `@link_name` 导出可供 C 调用的符号、编译可复用的静态库与动态库，并将 Zen C 集成到现有的 C 构建流水线中。
