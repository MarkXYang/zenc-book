# 附录 A：关键字

本附录列出了 Zen C 中保留的关键字，按用途进行分类，并附有上下文相关关键字或已弃用关键字的说明。

## 声明与类型

| 关键字 | 用途 |
| :--- | :--- |
| `fn` | 声明函数或方法。 |
| `let` | 声明变量绑定。 |
| `def` | 声明编译期常量（`def MAX = 100;`）。 |
| `struct` | 定义积类型（结构体）。 |
| `enum` | 定义和类型（带标签联合体 / 枚举）。 |
| `union` | 定义无标签的 C 风格联合体（`union` 在相同内存空间中重叠字段）。 |
| `trait` | 定义接口 / 行为契约。 |
| `impl` | 为类型实现方法或 `trait`。 |
| `alias` | 创建类型别名（`alias UserId = u64;`）。 |
| `opaque` | 声明跨模块或 FFI 边界的不透明类型。 |

## 模块、FFI 与底层互操作

| 关键字 | 用途 |
| :--- | :--- |
| `import` | 导入 Zen C 模块（`import "std/vec.zc"`）。 |
| `include` | 包含 C 头文件（`include <stdio.h>`）。 |
| `use` | 将命名空间或符号引入作用域。 |
| `extern` | 声明外部 C 函数或全局变量。 |
| `raw` | 输出原样 C 代码（`raw { ... }`）。 |
| `asm` | 嵌入内联汇编（`asm { ... }`）。 |
| `volatile` | 将内存访问或内联汇编块标记为 volatile。 |

## 控制流与逻辑运算符

| 关键字 | 用途 |
| :--- | :--- |
| `if` / `else` | 条件分支。 |
| `match` | 针对枚举、整数和值的模式匹配。 |
| `for` / `in` | 遍历范围或集合（`for i in 0..10`）。 |
| `while` | 条件控制循环（`while cond { ... }`）。 |
| `loop` | 无限循环（`loop { ... }`，通过 `break` 或 `return` 退出）。 |
| `break` / `continue` | 退出或跳入外层循环的下一次迭代。 |
| `return` | 从函数中返回值。 |
| `defer` | 安排在当前作用域退出时执行的清理代码。 |
| `and` / `or` / `not` | 词形逻辑运算符（等价于 `&&`、`||`、`!`）。 |

## 元编程、测试与诊断

| 关键字 | 用途 |
| :--- | :--- |
| `comptime` | 在编译期执行代码块（`comptime { yield("..."); }`）。 |
| `embed` | 在编译期将文件嵌入为字节切片、数组或 `string`。 |
| `sizeof` | 计算类型或表达式在编译期的字节大小。 |
| `test` | 声明单元测试块（`test "name" { ... }`）。 |
| `assert` | 运行时断言（`assert(cond, "message")`）。 |
| `expect` | 测试期望 / 诊断断言。 |

## 已移除的关键字

以下关键字曾在 Zen C 的早期原型中存在，现已从语言中**移除**。使用它们会触发编译器诊断，提示现代替代方案：

- `async` / `await` —— 移除，推荐使用显式的操作系统线程（`std/thread.zc`）与结构化并发。
- `autofree` —— 移除，推荐使用确定性的 `defer` 清理与 RAII 风格的 `Drop` 模式。
- `do`（例如 `do { ... } while ...`）、`repeat`、`guard`、`unless` —— 移除，以保持控制流的最小化（`loop`、`while`、`if !cond { return; }`）。
