# 使用结构体组织数据

*结构体（struct）*是一种自定义复合数据类型，允许你将多个相关的命名值打包封装为一个有意义的独立单元。如果你熟悉传统 C 语言，Zen C 中的结构体承担着相同的基石角色，用于定义内存中的结构化数据。然而，Zen C 对结构体进行了现代化升级，在兼具高性能、可预测的 C11 内存布局的同时，引入了现代语言中广受欢迎的人体工程学特性：

- **简洁的结构体定义**：采用清晰的类型优先与符合 Zen C 风格的语法声明字段。
- **严格初始化**：强制完整初始化所有字段或显式零初始化（`Struct{}`），杜绝未初始化内存错误。
- **符合人体工程学的字段访问**：统一的点号（`.`）语法，同时适用于直接结构体值和结构体指针。
- **模式匹配与解构**：使用简写或重命名语法将结构体字段直接提取到局部变量中。
- **组合与 Mixin（`use`）**：通过具名组合或带有自动方法转发的 mixin 扁平化嵌入结构体。
- **方法语法与 `impl` 块**：直接为类型关联行为、只读方法（`const self`）、可变方法（`self`）以及构造函数（`Struct::new()`）。
