# 通用编程概念

本章将介绍几乎在所有编程语言中都会出现的概念，以及它们在 Zen C 中的工作方式。如果你有 C、C++、Rust 或 JavaScript 的经验，会对其中的许多概念感到熟悉，但 Zen C 为它们带来了现代语言的人体工学特性与安全保证。

在本章中，你将学习到：

- **变量与常量**：理解编译期显式常量（`def`）、变量（`let`）、类型推导以及只读类型限定修饰（`const`）。
- **数据类型**：标量基础类型（整数、浮点数、布尔值、字符、字符串）、固定大小数组（`T[N]`）以及元组。
- **函数**：定义函数（`fn`）、参数类型、显式返回类型（`-> T`）、命名参数、`const` 参数以及默认参数。
- **注释、打印与字符串插值**：标准输出关键字（`println`）、字符串简写、隐式 `{}` 插值、原始字符串（`r"..."`）、多行字符串块（`"""`）以及交互式输入提示符（`?`）。
- **控制流**：使用条件表达式（`if / else if / else`）、重复循环（`while`、`for`、`loop`、`break`、`continue`）以及使用 `if` 的提前返回保护子句。

> [!NOTE]
> 闭包（Lambda）和原始函数指针（`fn*`）等高级函数式特性将在[第 14 章](ch14-00-functional-features.md)中讨论。带标签联合体的模式匹配将在[第 6 章](ch06-00-enums.md)中深入探讨。

让我们从变量和常量开始吧！
