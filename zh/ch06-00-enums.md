# 枚举与模式匹配

在 [第 5 章](ch05-00-structs.md) 中，我们探讨了结构体，它允许你将多个相关字段打包成单个复合类型。结构体是*积类型（Product Types）*（$A \times B$）：结构体的一个实例同时包含字段 $A$ **和**字段 $B$。

然而，在实际的系统编程中，经常需要对在任意给定时刻只能是若干种可能选择之一的值进行建模：
- 网络连接要么处于 **Connecting**，要么是 **Connected**、**Idle** 或 **Closed**。
- HTTP 响应要么返回 **Success** 载荷，要么返回 **Error** 错误码。
- 用户界面事件要么是带有坐标的**鼠标点击**，要么是带有字符编码的**按键**，要么是**退出**请求。

为了安全且富有表现力地表示这些数据结构，Zen C 提供了**枚举（Enums）**（*和类型 / Sum Types* 或*带标签的联合体 / Tagged Unions*）。
