# 所有权、指针与清理

内存管理是系统编程中最关键的方面之一。传统 C 语言赋予程序员对内存分配（`malloc`/`free`）的完全自由，但这往往伴随着频繁的错误：内存泄漏、双重释放（double free）以及释放后使用（use-after-free）漏洞。另一方面，托管语言依赖垃圾回收器（GC），从而引入了不确定的执行暂停和内存开销。

Zen C 采取了一种不同的途径：**兼具人体工程学安全性与移动语义的手动内存管理**。

在 Zen C 中，你既能保留完全的 C 级别控制力和极致性能，又无需承担任何运行时垃圾回收的开销。同时，语言提供了强大的特性来消除内存错误：

- **栈与堆及移动语义**：拥有资源的所有权类型不能被意外复制；赋值默认转移所有权，从而在编译期杜绝双重释放错误。
- **指针作为借用**：符合人体工程学的指针（`T*`、`&x`）允许在不转移所有权的前提下借用对数据的访问权。Zen C 支持统一的点号语法（`ptr.field`）、自动解引用、安全导航（`?.`）以及空值合并（`??`）。
- **切片**：传递连续内存视图（`std/slice.zc`），无需进行堆分配或缓冲区复制。
- **确定性清理**：基于作用域的 `defer`（后进先出 LIFO 执行），包括针对堆指针的 `defer free(p)`；通过 `Drop` trait 实现自定义析构函数；以及在所有权交接时使用 `.forget()` 解除清理。
