# 入门

让我们开启你的 Zen C 之旅！

Zen C 中有很多值得探索的内容，但每一段旅程都要从最初的起点开始。在本章中，我们将讨论：

- **安装**：在 Linux、macOS 或 Windows/WSL 上安装 `zc` 编译器，以及配置后端依赖项（GCC、Clang 或 TCC）。
- **编写“Hello, World!”程序**：创建你的第一个项目目录，编写 `.zc` 源代码，理解 Zen C 的基本语法，并编译/运行可执行程序。
- **掌握 `zc`**：了解 `zc` 命令行工具链的工作原理（`build`、`run`、`check`、`transpile`），配置编译器选项，并查看生成的标准 C11 代码。

让我们先从在你的计算机上搭建 Zen C 工具链开始吧！
