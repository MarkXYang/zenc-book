# 模块与多文件项目

在前几章中，我们编写的都是保存在单个文件中的小型程序。随着代码库规模和复杂度的增加，将所有代码保存在一个文件中很快就会变得难以维护。大型软件项目需要将代码拆分为逻辑模块、管理依赖项、防止命名冲突，并严格封装内部实现细节。

在传统 C 语言中，项目组织依赖于预处理器的 `#include` 指令。由于 `#include` 只是执行简单的文本复制粘贴，因此 C 项目饱受脆弱的头文件保护符（`#ifndef FOO_H`）、缓慢的编译速度、跨编译单元的宏污染以及缺乏真正命名空间的困扰。

Zen C 用现代、高性能的**模块系统**取代了这些遗留机制。
