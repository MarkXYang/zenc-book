# 第 19 章：编译期执行与元编程

Zen C 的核心优势之一是它直接转译为干净、可读的 C11。Zen C 中的元编程直接建立在该架构之上：Zen C 没有发明一套独立的、不透明的预处理器宏语言，而是为你提供了结构化的编译期工具，这些工具在 C 编译器运行之前生成或配置 C 代码。

在本章中，你将学习如何：

- 使用 `comptime` 块和 `@comptime` 函数在编译期运行 Zen C 代码，并通过 `yield(...)` 输出生成的声明或语句。
- 使用属性（`@packed`、`@align`、`@inline`、`@constructor`）和 `@derive(...)` 控制内存布局、内联、生命周期钩子以及自动 trait 生成。
- 使用 `embed` 将二进制和文本静态资源直接嵌入到可执行文件中，并通过原生编译器插件扩展转译器本身。
- 使用 `@cfg(...)` 和 `//> define:` 指令以及传统的 C 预处理器宏（`#define`、`#ifdef`）对平台特定代码进行门控。

本章中的每个可运行示例都位于 `examples/ch19/` 下，可以直接通过 `zc run -q` 执行。
