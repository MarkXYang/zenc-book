# 介绍

> 注意：本书此版本假设你正在使用 Zen C v0.4.4 或更高版本。

欢迎阅读**《Zen C 程序设计语言》**，这是一本关于 **Zen C**（`zenc`）的入门书籍。
Zen C 是一种现代系统编程语言，旨在将高级语言的人机工程学与 C 语言的原生速度、绝对掌控力以及零运行时开销保证融为一体。

纵观历史，系统级开发者往往被迫在光谱的两端之间做出取舍：
1. **经典 C 语言（C11/C23）**：极其透明、轻量且具备通用的 ABI，但缺乏现代语言的人体工学特性 —— 饱受手动内存跟踪、较弱的类型系统、冗长的语法以及缺乏代数数据类型的困扰。
2. **现代重型系统语言**：拥有丰富的类型系统、安全性与现代语法，但伴随而来的是复杂的运行时、庞大的工具链、不兼容的 ABI 或是巨大的编译开销。

**Zen C** 打破了这种妥协。它通过将代码干净地转译为标准 GNU C11，把模式匹配、零开销泛型、隐式资源管理（RAII）、Trait 以及原生基于线程的并发特性直接带入了 C 语言生态中。

---

## 现代语法体验。纯粹 C 语言。

Zen C 围绕以下几项基本原则进行设计：

### 1. 透明转译
Zen C 代码在调用 GCC、Clang 或 TCC 等宿主编译器之前，会被编译为标准且人类可读的 C11 代码。这里没有任何黑盒：你在 Zen C 中所写的一切，都会直接映射为干净、地道的 C 结构，绝无运行时膨胀。

### 2. 零 FFI 互操作
由于 Zen C 生成原生 C 代码并遵循标准 C ABI，因此你可以直接调用任何 C 头文件函数或传递任何 C 结构体，无需编写任何 FFI 包装层或生成绑定代码。此外，Zen C 还能无缝与 C++、Objective-C 和 CUDA 进行互操作。

### 3. 自动资源管理（RAII）
通过隐式 `Drop` trait，Zen C 能够在变量离开作用域时自动清理资源（内存分配、文件描述符、套接字、互斥锁）。这让你在无需承担垃圾回收器延迟开销的前提下，获得了防范内存泄漏和二次释放的安全保障。

### 4. 富有表现力的类型系统与安全性
借助类型推导（`let`）、显式常量（`def`）、模式匹配（`match`）、Option/Result 类型以及零开销泛型（单态化），Zen C 在编译阶段即可杜绝整类常见的软件缺陷。

## 本书读者对象

本书适合所有对编写高性能系统软件感兴趣的读者：

- 希望使用泛型、模式匹配、RAII 和字符串插值等现代语言特性，同时又不愿牺牲对内存布局的控制权或 C ABI 兼容性的 **C 语言开发者**。
- 正在构建操作系统组件、嵌入式应用、微服务、游戏引擎或高吞吐网络服务器的**系统工程师**。
- 来自 Rust、C++、Go 或 Python 阵营，希望寻找一种轻量级、易于读写且能顺畅集成到现有代码库中的系统语言的**多语言开发者**。

## 如何使用本书

本书由浅入深、循序渐进地组织了各个章节：

- **第 1 章：入门** 将引导你完成 `zc` 编译器的安装与环境配置，编写第一个“Hello, World!”程序，并熟练掌握 `zc` 命令行工具链。
- **第 2 章** 是一个实战教程，你将构建一个交互式猜数游戏，以直观体会 Zen C 的语法和标准库。
- **第 3 章至第 10 章** 涵盖语言核心概念：变量、内存管理、结构体、枚举、模块、集合、错误处理、泛型以及 Trait。
- **第 11 章至第 13 章** 介绍测试与调试、调用 C 语言库，并完成一个命令行实战项目（`zgrep`）。
- **第 14 章至第 20 章** 深入探讨进阶主题：闭包与迭代器、`zc` 工具链、高级内存管理、线程与工作线程池、Trait 对象、元编程以及系统级编程（内联汇编、SIMD、MISRA、C++/CUDA 互操作）。
- **第 21 章** 综合所有知识实现终极项目：一个多线程 Web 服务器。

让我们从 **第 1 章：入门** 开始这段探索之旅吧！
